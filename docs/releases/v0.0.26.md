# RAI Engine v0.0.26 — Dark World Visuals

**Pre-alpha release candidate**

This update builds on the Hi-Detail ASCII renderer and expands the world atmosphere.

## Dead Forest

- 2 new procedural dead-tree mesh variants
- 18 dead trees placed around the expanded world
- trees are normal Scene entities
- trees appear in Hierarchy
- Move / Rotate / Scale gizmos work
- trees can be saved with F5
- basic collision enabled

## Grass Wind

World-space grass glyphs now animate in the vertex shader.

Grass symbols:
- `'`
- `/`
- `\`
- `|`

The grass stays anchored near the ground while the upper part sways using two combined wind waves.

Dead-grass patches are also taller and denser than v0.0.25.

## Campfires

- procedural campfire-base mesh
- 3 campfires placed in the world
- animated world-space ASCII flames
- animated rising sparks
- flame glyphs use `+`, `*`, `^`, `'`
- warm glyph colors flicker in the world-space vertex shader

Campfires are placed near:
- `(1.8, -6.3)`
- `(-6.6, 3.6)`
- `(8.2, 8.4)`

## Atmosphere

The Hi-Detail ASCII postprocess now adds subtle dark atmospheric haze:
- lower contrast toward the visually distant/top region
- gentle edge atmosphere
- cold gray tint
- true-black background remains black

This is currently screen-space atmosphere, not physical volumetric fog.

## Existing v0.0.25 Features Preserved

- 4× denser ASCII image than the old 8×12 cell mode
- directional outline glyphs:
  `/ \ | ( ) [ ] { } _ =`
- 32-glyph atlas
- world-space glyph terrain
- 22 rocks
- ruined shrine
- broken watchtower
- editor Hierarchy / Inspector / gizmos
- F5 / F9 Scene save/load

## Architecture

```text
3D World
  -> normal depth + lighting
  -> Hi-Detail ASCII + outline classifier
  -> atmospheric haze

World Glyph Layer
  -> ash / stone / grass
  -> wind animation
  -> fire / spark animation
  -> scene depth test

Editor
  -> same Scene + Renderer
```

## Status

Pre-alpha. Visual systems are still being iterated quickly.
