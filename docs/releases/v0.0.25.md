# RAI Engine v0.0.25 — Hi-Detail ASCII World

**Pre-alpha release**

This release is the first major visual/editor milestone after v0.0.15.

## Hi-Detail ASCII Renderer

- ASCII cell size reduced from **8×12 to 4×6**
- approximately **4× more ASCII cells on screen**
- 32-glyph atlas
- directional silhouette analysis
- object contours can now use:
  - `/`
  - `\`
  - `|`
  - `(`
  - `)`
  - `[`
  - `]`
  - `{`
  - `}`
  - `_`
  - `=`
- strong edges receive brighter, more readable outline glyphs
- temporal stabilization retained and tuned for the higher glyph density
- normal surface shading still uses the stable `. : - + * # @` fill palette

## World-space Glyph Rendering

- environment glyphs exist at real 3D positions
- depth-tested world glyph rendering
- ash / dead-grass / stone material patches
- expanded terrain symbol set
- coherent negative space instead of a uniform full-screen pattern

## Expanded World

- movement area expanded from roughly ±4 to **±17**
- glyph terrain expanded to **±18.25**
- larger Ground entity
- 22 placed procedural rocks
- 3 procedural rock mesh variants
- Ruined Shrine
- Broken Watchtower

## Editor

Since v0.0.15 the project also gained:

- Editor Mode
- Hierarchy
- Inspector
- create / duplicate / delete
- transform editing
- Move / Rotate / Scale gizmos
- World / Local gizmo mode
- Scene JSON save/load
- runtime selection highlighting

## Rendering Architecture

RAI now uses a hybrid approach:

```text
3D meshes
  -> lighting / depth
  -> Hi-Detail ASCII postprocess
  -> contour glyph classification

environment
  -> world-space GlyphRenderer
  -> depth-tested glyphs

editor
  -> shared Scene / Renderer
  -> ImGui + ImGuizmo overlay
```
