# RAI Engine v0.0.27 — Animated Knight Player

**Pre-alpha release candidate**

This release replaces the old player cube with a real animated knight built from
modular 3D parts and rendered through the existing Hi-Detail ASCII pipeline.

## Main Feature

- Player is now an **animated knight**
- no more simple cube as the main hero
- the knight is built from multiple 3D parts:
  - boots
  - legs
  - pelvis
  - armored torso
  - tabard
  - cape
  - shoulders
  - helmet
  - visor
  - crest
  - sword
  - shield
  - belt

## Animation

The knight now has motion-driven animation:

### Idle
- subtle breathing
- soft body bob
- gentle cape sway

### Walk / Move
- leg swing
- opposite arm swing
- torso twist
- stronger body bob
- animated shield / sword motion
- cape reacts more strongly

Movement is detected from the player position over time, so animation changes
automatically while you move.

## Editor Compatibility

- the player is still the same scene entity (`Player` / `player_placeholder`)
- save/load still works
- selection still works
- player duplication/deletion protections remain
- editor highlight still works

## Existing 0.0.26 Features Preserved

- Hi-Detail ASCII renderer
- outline glyphs `/ \ | ( ) [ ] { } _ =`
- dead trees
- campfires
- fire sparks
- moving grass
- dark atmosphere haze
- expanded world
- shrine / watchtower / rocks
- editor UI / gizmos / F5 / F9
