# RAI v0.0.27 — Animated Knight Player

**Pre-alpha**

v0.0.27 replaces the original player placeholder with the first animated character in RAI.

## Added

- modular armored knight player;
- helmet and visor;
- crest;
- armor torso;
- shoulder plates;
- articulated arms and legs;
- boots;
- red tabard;
- animated cape;
- sword;
- shield;
- belt.

## Animation

The character now supports:

### Idle

- subtle breathing;
- small body movement;
- cape sway.

### Walking

- alternating leg animation;
- opposite arm swing;
- sword and shield motion;
- torso twist;
- stronger body bob;
- stronger cape movement.

The walk state is now driven by actual player displacement after collision resolution.

The knight also smoothly rotates toward the real movement direction.

## Fixed after initial 0.0.27 build

The first implementation visually appeared static and the knight continued facing one direction.

The final v0.0.27 fixes this by:

- storing runtime player velocity;
- calculating movement after `CollisionSystem::Move`;
- driving animation from `runtimeMoveAmount`;
- rotating Player toward its real movement vector;
- increasing limb animation amplitude;
- adding visible local forward/back movement to arms and legs.

## Preserved

All major v0.0.26 features remain:

- Hi-Detail ASCII renderer;
- directional ASCII outlines;
- world-space glyph renderer;
- expanded world;
- rocks;
- ruined shrine;
- broken watchtower;
- dead trees;
- moving grass;
- campfires;
- sparks;
- atmospheric haze;
- editor Hierarchy / Inspector;
- ImGuizmo transforms;
- scene save/load.

## Status

This is still a **pre-alpha** release.

Next major gameplay milestone is expected to focus on enemies and the beginning of melee combat.
